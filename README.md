# AG Grid Subject Prototype

Angular 17 + TypeScript prototype showing products grouped under editable subjects using AG Grid Enterprise.

## Features

- Products grouped by subject
- Subject shown once at group level
- Double-click a subject to rename it
- Drag product rows between subjects
- Subject/group rows cannot be dragged
- Editable quantity
- Price and line total columns

## Run locally

```bash
npm install
npm start
```
